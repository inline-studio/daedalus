DAEDALUS

Your daedalus runs on a server; this app is its interface. Chat and agents stay server-side — commands and file edits can run here on this machine, under your control.

The web channel address — your proxy (e.g. https://chat.example.com) or a local port (e.g. http://127.0.0.1:8765). You'll log in on the next screen.
Local execution Conversations started here run their commands and file edits on THIS machine (inside the workspace below) instead of on the server. You can switch per conversation later.
Free rein Skip the per-command approval prompt. Dangerous commands (rm -rf, sudo, …) always ask regardless.
Workspace Commands run in this folder; file operations are confined to it. Created automatically if it doesn't exist.
